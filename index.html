Bubble Sort

Repeatedly steps through the list, compares adjacent elements and swaps them if they're in the wrong order. The largest unsorted element "bubbles up" to its correct position each pass.

Time & Space Complexity
Best case O(n)
Average O(n²)
Worst case O(n²)
Space O(1)
How it works
  1. Compare two adjacent elements
  2. Swap them if the left is greater
  3. Repeat until the end of the pass
  4. Each pass "bubbles up" the largest element
  5. Stop when no swaps occur in a pass
